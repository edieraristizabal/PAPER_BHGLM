# PAPER_BHGLM

**The dominant role of latent spatial structure in landslide susceptibility**
E. Aristizábal, L. Lombardo and O. Korup — *Natural Hazards and Earth System Sciences* (egusphere-2026-1749), revised version.

Spatial hierarchical generalized linear models (Poisson, basin-level random intercepts and ICAR, BYM and Leroux catchment-level effects, fitted with R-INLA) for catchment-level landslide counts in the northern Colombian Andes.

## Repository structure

| Folder | Content |
|---|---|
| `DATA/` | Model inputs: 526 catchments with predictors and landslide counts (`df_catchments_kmeans.gpkg`), point inventory of landslide crowns (`inventarioV1.shp`, reproduces the counts in all 526 catchments), candidate predictors used for screening (`catchments_with_new_predictors.csv`). |
| `CODES/` | Scripts that produce every result, table and figure of the paper (see below). |
| `RESULTS/` | Outputs of the analyses: cross-validation, credible intervals, response-distribution diagnostics (`EC7/`), spatial-support analyses (`EC4/`) and the LaTeX tables of Appendix A (`appendix_tables/`). |
| `FIGURES/` | Final figures of the manuscript (Figs. 1–7, workflow diagram, Figs. A1–A4). |
| `MANUSCRIPT/` | LaTeX source of the revised manuscript: `manuscript_marked.tex` (changes highlighted: yellow = Reviewer 1, green = Reviewer 2, cyan = Editor) and `manuscript_clean.tex`, with the bibliography and the Copernicus class files. Compile inside `MANUSCRIPT/`; figures are read from `../FIGURES/`. |

## Workflow

All scripts are run from the repository root.

| Script | Produces |
|---|---|
| `CODES/predictor_screening.py` | Candidate predictors and their correlation matrix (`RESULTS/TableS1_correlation_matrix.csv`, Table A2) |
| `CODES/INLA.R` | Models M1–M5 (Table 1) |
| `CODES/extract_credible_intervals.R`, `CODES/extract_random_effects.R` | Posterior summaries of the first revision |
| `CODES/linearity_check.py` | Linearity tests of the first revision |
| `CODES/spatial_cross_validation.R` | Spatially blocked cross-validation, per-fold RMSE of the posterior mean (Table A5) |
| `CODES/ec7_response_distribution.R`, `CODES/ec7_followup.R` | Overdispersion, alternative likelihoods, posterior predictive checks, sensitivity to influential catchments; single archived run of M1–M5 (Tables 1, A4, A7; Fig. A4) |
| `CODES/ec4_zonal_12m.R` → `CODES/ec4_aggregation_sensitivity.R` → `CODES/ec4_slope_scale.R` → `CODES/ec4_figure.R` | Spatial support and slope-scale control (Appendix A6, Table A8, Fig. A5) |
| `CODES/levelB_models.R` | Model-specification checks: non-spatial overdispersed baseline, BYM2 and PC priors, basin level, lithology and land cover, rw2 effects, negative control, two-sided Moran's I, overdispersion-corrected linearity tests, PCA (Appendix A2 and A7; Tables A3 and A9) |
| `CODES/levelB_cv.R` | Cross-validation with proper predictive scores (log score, CRPS, predictive median), three spatial and one random partition (Table A6) |
| `CODES/figures_main.R` | Figs. 2b, 3b, 4–8 and A3 |
| `CODES/appendix_material.R` | Figs. A1–A2 and the LaTeX tables of Appendix A (`RESULTS/appendix_tables/`) |
| `CODES/flow.json` | Source of the workflow diagram (Fig. 1) |

Figure files are named after their number in the manuscript (e.g. `Fig04_M1_poisson.jpg` is Fig. 4). Fig. 2a (study area) and Fig. 3a (neighbour graph) were produced in a GIS and are provided as final images.

## External data not included

- 12.5 m ALOS-PALSAR DEM (`DEM_filled_12m.tif`) and the drainage network (`drainage_network_5km2.gpkg`), used by `predictor_screening.py`, `ec4_zonal_12m.R` and `ec4_slope_scale.R`; the DEM is available from the Alaska Satellite Facility. Set the path at the top of those scripts.
- The 25 m rasters derived from it (`DATA/*_25m.tif`, ~1 GB each) are regenerated by `predictor_screening.py`.
